# Deepfake Detection

This project detects deepfake images using a trained ResNet50 model.

## Download Model

Download the model from:

ضع_رابط_جوجل_درايف_هنا

After downloading:

1. Place the file `deepfake_model_150px.pth`
2. Put it in the project root folder
3. Run the application

## Run

```bash
pip install -r requirements.txt
python app.py
```
